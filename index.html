From discovery to desktop

A small library of views worth keeping.

Start with a mood, a subject, or a search. Morrow brings the image, its source details, and the tools to keep or use it together in one native Mac app.

⌕

Find your next view

Explore For You or browse Nature, Architecture, Minimal, Ocean, and Abstract. Choose Wallhaven for no-key, public SFW search in the General category (excluding Anime and People), or Pixabay with your own API key. If Pixabay has no key, Morrow stays on Pixabay instead of silently switching sources.

♡

Make it yours

Save favorites right from the grid. Build named collections for different moods and spaces, and return to them whenever you want.

↓

Keep it close

Store the full-resolution original offline, independent of favorites. Preview it or apply it later—even when you’re away from a connection.

◉

Know what you’re seeing

See a 4K, Full HD, HD, or Standard label and dimensions for the best known rendition Morrow can apply. When available, compare original dimensions and file size separately. Upload dates appear when a provider supplies them; Pixabay does not provide dates. Source and rights details link to the image’s Wallhaven, Pixabay, or saved Commons page.

▧

Download or set

Download the best available rendition to a folder you choose, or apply it to every connected display. Morrow also keeps a copy in your Pictures folder.

⌘

Stay in your own flow

No Morrow account, analytics, advertising, or scheduled rotation. Choose public SFW Wallhaven search in the General category (excluding Anime and People) or Pixabay in Settings; Pixabay requires your own API key and never silently switches sources.

A simple path from search to screen

Discover. Decide. Settle in.

Morrow sends native search requests directly from your Mac to your selected provider. Wallhaven provides public SFW search in the General category only (excluding Anime and People), without a key. Pixabay requires an API key; if one is missing, Morrow asks you to add it and does not switch sources. Pixabay search responses are cached for 24 hours, and its image URLs are temporary display URLs—not permanent hotlinks. Use Morrow’s local download or offline-save actions to keep an image.

Your library stays local

Keep your favorites on your Mac.

Morrow has no account system, analytics, advertising, or cloud sync. Search requests go directly from your Mac to Wallhaven or Pixabay, based on your selected source. Wallhaven receives SFW search terms and a General-category-only filter, excluding Anime and People; Pixabay receives your API key and search terms only when selected. A key entered in Settings is stored in macOS Keychain. Existing Commons images remain in your library and may still be loaded from Wikimedia.

✓Favorites and collections are saved in the app’s local preferences.
✓Offline originals are saved in Morrow’s sandboxed Application Support folder.
✓Applied wallpapers are copied to ~/Pictures/Morrow Wallpapers.
✓Downloads go to the location you select.

Source details for every image

Morrow identifies Wallhaven or Pixabay in new search results, displays available creator and rights details, and links back to the source page. Existing Commons items retain their original attribution. Morrow is independent and is not endorsed by these providers.

Sources, distinct rights

Wallhaven images remain the property of their respective owners; review each linked page for rights and usage information. Pixabay images are provided under the Pixabay Content License. Existing Commons items retain their CC0 metadata, which is community-maintained and not a legal guarantee. Pixabay's API guidance recommends server-side downloads; Morrow uses direct client requests and does not claim Pixabay has approved this architecture.

Native SwiftUI · macOS 14+

Made for the Mac desktop.

Build Morrow from source with a full Xcode installation. The project has no third-party package dependencies and includes a script that builds the app and packages a disk image. Developers can copy the included example to Git-ignored Morrow/Config/LocalSecrets.xcconfig for a local Debug-only key; Release builds do not include it.

./build.sh
Build outputs.build/Build/Products/Release/Morrow.app
Morrow.dmg at the repository root

The current build is ad-hoc signed and not notarized. For broad distribution, use Developer ID signing and notarization.
